# 경진대회 참가 안내 (학생용)

> 교수자 메모: `<사이트 주소>`, `<저장소 주소>` 를 실제 값으로 바꾼 뒤 LMS 등에 올려 쓰십시오.

## 1. 준비

1. GitHub 계정을 만듭니다 (https://github.com). 이미 있으면 그대로 사용합니다.
2. 수업에서 안내한 양식에 **학번, 이름, GitHub 아이디, 팀명**을 제출합니다. 명단에 없는 계정의 제출은 채점되지 않습니다.
3. 대회 사이트 `<사이트 주소>` 에서 대회를 고르고 **데이터** 탭에서 `train.csv`, `test.csv`, `sample_submission.csv` 를 내려받습니다.

## 2. 제출 파일 만들기

- `sample_submission.csv` 와 **열 이름이 같고**, `test.csv` 의 모든 id 가 **빠짐없이 한 번씩** 들어 있어야 합니다.
- 예측값 열에 빈칸이나 문자가 있으면 채점되지 않습니다.
- UTF-8 로 저장합니다 (pandas: `df.to_csv("submission.csv", index=False)`).

## 3. 제출하기 (이슈 방식)

1. 대회 사이트의 **제출 방법 탭 → 제출 파일 암호화** 버튼(또는 `<사이트 주소>encrypt.html`)에서 대회를 고르고 CSV 파일을 선택합니다. 열 이름과 행 수가 맞는지 검사해 주고, **암호화해서 내려받기**를 누르면 `submission_..._.enc.txt` 파일이 저장됩니다. 다른 참가자가 여러분의 예측을 볼 수 없게 하기 위한 절차이며, 파일은 브라우저 안에서만 처리됩니다.
2. 같은 화면의 **제출하기(새 이슈 열기)** 버튼을 누릅니다 (GitHub 로그인 필요). **대회**가 제대로 선택되어 있는지 확인합니다.
3. **제출 파일** 칸에 1번에서 받은 `.enc.txt` 파일을 끌어다 놓습니다. 업로드가 끝나면 `[파일명](https://github.com/user-attachments/...)` 형태의 링크가 자동으로 들어갑니다. 링크가 생길 때까지 기다리세요. 암호화하지 않은 CSV 를 올리면 채점되지 않습니다.
4. 메모(선택)에 모델·특징을 짧게 적고 **Create** 를 누릅니다.
5. 1~3분 뒤 이슈에 ✅ 점수 댓글이 달리고 사이트 리더보드가 갱신됩니다. ❌ 댓글이 달리면 사유를 읽고 파일을 고쳐 **새 이슈**로 다시 제출합니다 (실패한 제출은 횟수에 포함되지 않습니다).

제출이 몰리는 시간(특히 마감 직전)에는 댓글이 늦어질 수 있습니다. 마감 판정은 **이슈를 만든 시각** 기준이므로 늦게 채점되어도 불이익은 없습니다.

## 4. 규칙 요약

- 하루 제출 횟수 제한이 있습니다 (대회 페이지 규칙 참고, 한국 시간 자정 초기화, 팀은 팀 전체가 공유).
- 리더보드의 Public 점수는 테스트 데이터의 **일부**로 계산한 값입니다. 최종 순위는 마감 후 나머지(Private) 데이터로 다시 계산되며, 각 참가자(팀)의 Public 상위 N개 제출물 가운데 Private 점수가 가장 좋은 것이 사용됩니다. Public 점수에 과적합하지 않도록 교차검증을 활용하세요.
- 다른 참가자의 제출 파일을 그대로 내면 자동으로 표시되며 부정행위로 처리됩니다.
- 테스트 데이터의 정답을 추정하기 위한 리더보드 탐색(probing)은 금지합니다.

## 5. PR 방식 제출 (교수자가 안내한 경우에만)

1. 저장소 `<저장소 주소>` 오른쪽 위 **Fork** (처음 한 번).
2. 내 Fork 에서 `submissions/<대회슬러그>/` 폴더로 들어가 **Add file → Upload files** 로 암호화한 `.enc.txt` 파일 하나를 올리고 **Commit changes**.
3. 내 Fork 첫 화면의 **Contribute → Open pull request → Create pull request**.
4. 1~3분 뒤 PR 에 점수 댓글이 달리고 PR 은 자동으로 닫힙니다. 다음 제출은 같은 절차를 반복합니다.
