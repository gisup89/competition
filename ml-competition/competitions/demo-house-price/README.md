# 대전 아파트 매매가 예측

면적·층·건축년도·역거리 등으로 아파트 매매가(만원)를 예측합니다 (합성 데이터)

## 개요

이 대회의 목표와 배경을 설명하세요.

## 데이터

- `train.csv` : 학습 데이터 (입력 변수 + 정답 `price`)
- `test.csv` : 테스트 데이터 (입력 변수만 포함)
- `sample_submission.csv` : 제출 파일 형식

## 평가

- 평가지표: **RMSE** (Root Mean Squared Error)
- Public 리더보드는 테스트 데이터의 일부(30%)로 계산되며, 최종 순위는 마감 후 나머지(Private) 데이터로 산정합니다.
- 최종 평가에는 각 참가자(팀)의 Public 점수 상위 2개 제출물 가운데 Private 점수가 가장 좋은 것을 사용합니다.

## 제출 형식

`sample_submission.csv` 와 같은 열 구조의 CSV 파일을 제출합니다.

```
id,price
...
```

## 규칙

- 하루 최대 5회 제출 (한국 시간 기준 자정 초기화)
- 외부 데이터 사용 여부, 팀 구성 규칙 등을 여기에 적으세요.
